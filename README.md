# Running Tracker

Простой одностраничный трекер пробежек. Чистые HTML/CSS/JS, без сборщиков и зависимостей.

## Возможности

- Добавление пробежки: дата, дистанция (км), время (мм:сс или чч:мм:сс).
- Автоматический расчёт темпа (мин/км).
- Суммарный километраж за текущую неделю (пн–вс) и за всё время.
- История пробежек с сортировкой по дате и удалением записей.
- Хранение данных в `localStorage` — данные остаются после перезагрузки страницы.
- Тёмная тема, адаптивная вёрстка.

## Запуск

Никакой сборки и сервера не требуется — просто открыть `index.html` в браузере.

## Файлы

- `index.html` — разметка страницы.
- `style.css` — стили (тёмная тема).
- `app.js` — логика: хранение данных, валидация формы, расчёт статистики.
